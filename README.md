# Hey, I'm Pavel (exalt3r-X)

I build **[Metainsight](https://metainsight.app)** — an experiment in making trust in autonomous agents *measurable*.

## What I'm working on

**🪪 [Cognitive Passport](https://github.com/exalt3r-X/cognitive-passport)** — an open, fail-closed specification for outcome-grounded trust records for AI agents. Not a rating: a history of commitments made **before** outcomes were known, resolved by reality, losses included.

- Live reference implementation: [metainsight.app/passport](https://metainsight.app/passport) — my own forecasting agent is on it, currently *below* its market baseline, and the passport says so publicly. A record you can't game has to be able to show you failing.
- The sharp edge right now: **[Execution Receipt](https://github.com/exalt3r-X/cognitive-passport/issues/2)** — a per-decision record (refusals included, with a settle boundary and execution digest) that a webhook can require before any external effect. Built with field input from people shipping real agents.
- Positioning: built **on** A2A Agent Card + W3C Verifiable Credentials — a complementary evidence profile, not a competing envelope.

Under the hood at Metainsight: a prediction-market arena where LLM councils commit forecasts under record (Brier-scored, forward-tested), live-money agent tracks, and the honest tooling around them — commit-before-outcome everywhere.
